# Опис виконаних команд

Для виконання завдання (злиття двох незалежних репозиторіїв) були використані наступні команди:

1. `git init` — створення локального репозиторію.
2. `git add .` та `git commit -m "..."` — створення першого локального коміту.
3. Створення файлу через вебінтерфейс GitHub.
4. `git remote add origin <URL>` — підключення віддаленого репозиторію до локального.
5. `git pull origin main --allow-unrelated-histories` — **ключова команда**, яка дозволила об'єднати дві незалежні історії комітів (локальну та віддалену) без помилки "refusing to merge unrelated histories".
6. `git push -u origin main` — відправка об'єднаних даних на GitHub.
